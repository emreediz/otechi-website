# Cam kapsüller

Üç parçalı (sol uç · orta · sağ uç) kapsül görselleri. `src/components/visual/Capsule.tsx`
bu parçaları arka plan olarak dizer; yazı canlı HTML'dir.

| Dosyalar | Kaynak |
|---|---|
| `kapsul-turuncu-cam-*.webp` | Ole sitesinin kendi kapsül görselleri (olduğu gibi) |
| `kapsul-lacivert-cam-*.webp` | Ole sitesinin kendi kapsül görselleri (olduğu gibi) |
| `kapsul-yesil-cam-*.webp` | Turuncu kapsülden üretildi (tarayıcı canvas'ı, ton 160°, açıklık ×0.46) — Namaz Motivasyonu |

Sol/sağ uçlar 244×240, orta parça 16×240.
